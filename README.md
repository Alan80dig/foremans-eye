# FreePDFShoot

**Мгновенный приватный PDF-сканер. Без серверов. Без регистрации. Без сливов.**

---

## 🚀 Как это работает

1. **Снимаешь документ** — системная камера, идеальное качество.
2. **Обрезаешь лишнее** — расставь маркеры по углам.
3. **Отправляешь PDF** — многостраничный документ через любое приложение.

## 🔒 Почему это безопасно

- 📱 Всё на устройстве — вычисления только в браузере.
- 💨 Закрыл вкладку — всё исчезло.
- ☁️ Никаких облаков, серверов, регистраций.

---

## ⚠️ Важно

Ответственность за сохранность, отправку и использование созданных PDF-файлов полностью лежит на пользователе. Инструмент не имеет доступа к вашим файлам и не может их восстановить.

---

## 📱 Как запустить

Открой [FreePDFShoot](https://alan80dig.github.io/freepdfshoot/) **на смартфоне**. Инструмент работает только с камерой телефона.
